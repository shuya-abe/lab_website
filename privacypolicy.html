1. 適用範囲

本プライバシーポリシーは、福井工業大学 阿部研究室（以下「当研究室」）が運用または公開する次のものに適用されます。

  • 当研究室の Web サイトおよびその配下のページ・資料
  • 当研究室が公開するソフトウェア、ブラウザ拡張機能、ツール、デモ、データセット、ドキュメント等
  • 当研究室が教育研究目的で提供するオンライン上のコンテンツ全般

個別のサービスやソフトウェアに、より具体的な説明（権限の一覧、保存先の詳細など）がある場合は、 当該説明もあわせてご確認ください。本ポリシーと個別説明が併存する場合、個別説明が対象範囲について優先します。

2. 基本方針

当研究室は、教育研究およびその成果公開を目的として情報発信やツール提供を行います。 利用者のプライバシーを尊重し、必要以上の個人情報の取得・利用・提供を行いません。

3. 取得しうる情報

当研究室が取得しうる情報には、例えば次のものが含まれます。

3.1 利用者が自ら提供する情報

  • 問い合わせフォーム、メール、Issue、Pull Request 等を通じて送付される氏名、所属、連絡先、本文
  • イベント参加申込、質問、共同研究・利用相談等に関連して提供される情報

3.2 サイト・サービス利用時に自動的に記録されうる情報

  • アクセス日時、IP アドレス、ブラウザ種別、参照元 URL 等の通信・サーバログ
  • サイト運営のために必要な Cookie または類似技術（使用する場合）

なお、ホスティング先（大学、GitHub Pages、クラウド事業者等）の仕様により、 当該事業者側でアクセスログ等が取得・保管される場合があります。その取扱いは各事業者のポリシーにも従います。

3.3 ソフトウェア・拡張機能等における端末内データ

一部のソフトウェアやブラウザ拡張機能では、機能提供のために利用者の端末内（例: ブラウザのローカルストレージ）へ 設定値や作業中データを一時保存することがあります。 そのようなデータは、原則として運用者の外部サーバーへ自動送信しません。 詳細は各ソフトウェアの説明をご確認ください。

4. 利用目的

取得した情報は、次の目的の範囲で利用します。

  • 問い合わせ対応、連絡、サポート
  • 教育研究、教材公開、ソフトウェア公開・改善
  • サイトおよび提供サービスの運用、保守、セキュリティ確保
  • 不正利用の防止、障害対応
  • 法令に基づく対応

上記以外の目的で利用する場合は、あらかじめ本人の同意を得るか、法令に基づき許容される範囲で行います。

5. 第三者提供

当研究室は、法令に基づく場合、本人の同意がある場合、 または業務委託先に必要な範囲で取り扱わせる場合を除き、 取得した個人情報を第三者に提供しません。

サイトやリポジトリの公開・配信にあたり、ホスティング事業者等のインフラを利用する場合があります。 その際、サービス提供に必要な範囲でデータが当該事業者の管理下に置かれることがあります。

6. 外部サービス・リンク

当研究室のサイトや成果物から、Microsoft、Google、GitHub その他の外部サービスへリンクする場合があります。 リンク先における情報の取扱いについては、各事業者のプライバシーポリシーが適用されます。

7. 保存期間

取得した情報は、利用目的の達成に必要な期間、または法令で求められる期間、保管します。 不要となった情報は、合理的な方法で削除または匿名化します。

8. 安全管理

当研究室は、取り扱う情報の漏えい、滅失、き損等を防ぐため、 教育研究機関として合理的な範囲で安全管理に努めます。 ただし、インターネット通信の性質上、安全性を完全に保証するものではありません。

9. 利用者による公開・保存データについて

利用者が自ら作成・保存・公開したファイル（例: エクスポートした HTML、アップロード資料、投稿内容等）の管理は、 原則として利用者自身の責任となります。 個人情報や未公開情報を含む場合は、共有・公開前に十分ご確認ください。

10. 子どもの個人情報

当研究室は、子どもから積極的に個人情報を収集することを目的としていません。 保護者等からの削除要請等があった場合は、適切に対応します。

11. 開示・訂正・削除等の請求

ご本人から、保有個人情報の開示、訂正、削除、利用停止等の請求があった場合は、 本人確認のうえ、法令および学内規程等に従い、合理的な範囲で対応します。 下記連絡先までご連絡ください。

12. ポリシーの変更

本ポリシーの内容は、必要に応じて改定することがあります。 重要な変更を行う場合は、本ページの更新日を改定し、当研究室 Web サイト上で周知します。
